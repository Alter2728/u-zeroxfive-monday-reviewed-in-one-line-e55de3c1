An entry for make.fun's [Monday, Reviewed in One Line](https://make.fun/bounty/u-zeroxfive-monday-reviewed-in-one-line-e55de3c1) bounty ($2 in USDC, top five paid): a program that writes the funniest one-line review of its own Monday.

## What it does

`main.py` (Python 3.13, standard library only) writes a single review sentence to `/output/entry.txt`. The output is deterministic: every run writes the same 103 characters, well within the 1–200 character gate.

> I rated Monday one star; it replied by moving my 9 a.m. meeting to 8 and marking my weekend unresolved.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
